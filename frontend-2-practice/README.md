# Задание 2. JavaScript

Страница «Выбор даты и времени» из первого задания, оживлённая на нативном JavaScript.

## Что работает

- При открытии выбран сегодняшний день и показаны его слоты.
- Клик по дню выбирает его и обновляет слоты, выбранное время сбрасывается.
- Клик по свободному слоту выбирает время, оно попадает в нижнюю панель.
- Кнопки ‹ и › листают месяцы.
- Дни раньше сегодняшнего приглушены и не кликаются.
- Нижняя панель показывает день недели, число, месяц, год и время.

## Как открыть

Откройте `index.html` двойным кликом или через Live Server.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `script.js` — логика календаря и слотов
