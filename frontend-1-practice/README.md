# Итоговое задание 1. HTML/CSS

Вёрстка страницы «Выбор даты и времени» (шаг 3 записи в барбершоп) по макету из Figma.

## Как открыть

Откройте `index.html` двойным кликом или через Live Server в VS Code.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили
- `images/` — папка для картинок
