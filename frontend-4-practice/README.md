# Задание 4. Асинхронный JavaScript и создание React-приложений

Страница «Выбор даты и времени» на React. Данные («сегодня» и слоты) приходят
с имитационного сервера через fetch.

## Запуск

```
npm install
npm run dev
```

Откройте http://localhost:3000

## Эндпоинты

| Метод | URL | Что возвращает |
|---|---|---|
| GET | /api/booking/today | `{ day, month, year }` — «сегодня» |
| GET | /api/slots?day=&month=&year= | `{ date, slots }` — слоты на дату |

`month` 0-индексный (0 = январь).

Проверить в браузере:

- http://localhost:3000/api/booking/today
- http://localhost:3000/api/slots?day=17&month=9&year=2026

## Сценарии

1. При открытии видно «Загрузка…», потом календарь на месяц «сегодня» с сервера.
2. При клике по дню видно «Загрузка слотов…», потом слоты.
3. Ошибка сервера показывается текстом с кнопкой «Попробовать снова».
   Для проверки на 20 ноября 2026 сервер отвечает ошибкой 500
   (список дат — `failDates` в `server/database.js`).

## Структура

- `server/database.js` — «база данных»: today, слоты будней и выходных, даты с ошибкой
- `server/server.js` — плагин Vite, перехватывает `/api/*`, задержка `DELAY_MS`
- `src/api.js` — `fetchToday()` и `fetchSlots(date)`
- `src/App.jsx` — состояние, загрузка в `useEffect`, защита от гонок
- `src/components/` — компоненты страницы
- `src/data/date.js` — чистые функции для работы с датами
